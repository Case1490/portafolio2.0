# Portafolio — Renzo Ramos

Portafolio personal de Renzo Ramos, desarrollador full stack. Presenta proyectos, stack técnico, servicios y datos de contacto.

🔗 Sitio en vivo: [renzoramos.netlify.app](https://renzoramos.netlify.app/)

## Stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- EmailJS

## Desarrollo local

```bash
npm install
npm run dev       # servidor de desarrollo
npm run build     # build de producción
npm run preview   # previsualizar el build
```
